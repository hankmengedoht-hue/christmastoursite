# Home photographs

Drop one photograph per home into this folder, named to match its slot on the page:

```
home-1.jpg
home-2.jpg
home-3.jpg
home-4.jpg
home-5.jpg
home-6.jpg
```

- Portrait orientation, about 1200×1500 pixels, JPEG, under about 300 KB each.
- A photo appears on the site as soon as its file exists; until then the slot shows a drawn window and the home's number.
- After adding a photo, update that home's `alt` text in `index.html` to describe the picture.
- For more or fewer than six homes, copy or delete an `<li class="home">` block in `index.html`.
